# Frosty Dreams – Ice Cream Parlour Website

A modern ice cream parlour website concept designed to showcase ice cream products and provide an engaging browsing experience.

## Live Demo
https://myfirstrepository1-gray.vercel.app/

## Features
- Attractive homepage design
- Ice cream menu section
- Custom sundae builder interface
- Customer testimonials section
- Contact and reservation interface

## Technologies Used
- HTML
- CSS and JavaScript (include only if used in the project)

## Project Purpose
This project was developed as a web development learning project to practice website structure, frontend design, and user interface development.
